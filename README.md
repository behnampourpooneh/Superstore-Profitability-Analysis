# Superstore-Profitability-Analysis
Business Intelligence project using Power BI and Power Query to investigate the root causes of negative profitability in a retail business.

## Business Problem:
The company generated substantial sales revenue but reported an overall negative profit.
The objective of this project is to identify the root causes of the negative profitability and determine which business areas contribute most to the losses.

## Target Audience:
- Store Owner
- Sales Managers
- Finance Managers

## Project Objectives:
- Analyze sales performance
- Identify loss-making categories
- Evaluate profitability by region
- Investigate shipping performance
- Segment products based on profitability
